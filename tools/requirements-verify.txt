# Environment for the external SciPy/NumPy cross-check (Gradle task `setupScipyVerification`).
#
# The versions are pinned STRICTLY and deliberately. The cross-check is the only project
# verification that is not closed over the project's own code, so it must be reproducible:
# with floating versions a discrepancy could not be told apart from a change in the

#
# Updating the versions is a deliberate action: afterwards the `./gradlew scipyVerify` run must
# stay green and the new versions must land in this file (the cross-check script prints them
# itself and records them in the `environment` field of the machine-readable report).
