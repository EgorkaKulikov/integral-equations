# Реферат программы для ЭВМ

Материалы к заявке на государственную регистрацию программы для ЭВМ.

## Название программы

integral-equations — программа численного решения интегральных уравнений Фредгольма,
Вольтерры и Урысона методом сплайн-коллокации на квадратичных минимальных сплайнах.

## Правообладатель и автор

Куликов Егор Константинович, физическое лицо. Правообладатель и автор совпадают.

## Реферат

Программа предназначена для приближённого решения линейных и нелинейных интегральных
уравнений первого и второго рода методом сплайн-коллокации в базисе квадратичных минимальных
сплайнов. Область применения — вычислительная математика и прикладные задачи, сводящиеся
к интегральным уравнениям: восстановление входного сигнала по измеренному отклику,
обработка результатов косвенных измерений, задачи теории потенциала и переноса.

Существующие средства решают задачу частично. Библиотеки численных методов (SciPy,
Hipparchus, Apache Commons Math) предоставляют квадратуры и полиномиальные сплайны, но
не содержат готовых схем коллокации для интегральных уравнений и не допускают порождающих
систем, точно воспроизводящих гиперболические или тригонометрические функции. Схемы
повышенного порядка — итерация Слоана, схема Кулкарни, комбинированный оператор Нюстрёма —
в них отсутствуют, равно как и регуляризация уравнений первого рода с автоматическим
выбором параметра.

Программа обеспечивает следующие функциональные возможности: решение линейного уравнения
Фредгольма второго рода с постоянными пределами интегрирования; решение линейного уравнения
Вольтерры второго рода с переменным верхним пределом; решение нелинейного уравнения Урысона
второго рода методом Ньютона с аналитической матрицей Якоби; решение уравнений первого рода
с регуляризацией — сведением к уравнению второго рода, дифференцированием и стабилизатором
Тихонова с выбором параметра по принципу невязки Морозова; построение приближённого решения
семью схемами второго рода (базовая коллокация, итерация Слоана, схема Кулкарни и её
итерированный вариант, метод Нюстрёма, комбинированный оператор Нюстрёма и его итерированный
вариант); вычисление погрешности приближения и наблюдаемого порядка сходимости на
последовательности сеток; вывод таблиц численного эксперимента и измерение производительности.

Отличительные особенности программы состоят в следующем. Схемы строятся над произвольной
порождающей системой — полиномиальной, гиперболической, тригонометрической — и над пятью
семействами аппроксимационных функционалов, что расширяет класс точно воспроизводимых
функций по сравнению с полиномиальными реализациями. Итерационные схемы не могут вернуть
несошедшийся результат без явного признака: несходимость возбуждает исключение либо
отражается полями признака сходимости, числа итераций и достигнутой невязки. Контекст
вычислений, включающий выбор реализации BLAS/LAPACK и режим параллельной сборки матриц,
передаётся явно, а его рассогласование между решателем и его зависимостями отвергается
с диагностикой; результат сборки матриц побитово не зависит от режима параллельности.
Правильность реализации подтверждается средствами, не зависящими от кода программы:
аналитически точными решениями, опубликованными таблицами (708 значений, допуск 2 %),
сверкой со SciPy и NumPy по шести слоям вычислений, независимо реализованным методом
Нюстрёма и таблицей ожидаемых порядков сходимости для 168 сочетаний схемы, базиса
и семейства функционалов. Численное поведение зафиксировано характеризационными эталонами
из 1366 и 1344 значений с относительным допуском 1e-9.

## Тип ЭВМ

IBM PC-совместимые, Apple Silicon и иные, поддерживаемые виртуальной машиной Java версии 21.

## Язык программирования

Kotlin 2.0.

## Операционная система

Linux, macOS, Windows с установленной виртуальной машиной Java версии 21 или новее.

## Объём программы

Около 258 КБ исходного кода решателей (4028 строк в 11 файлах на языке Kotlin, каталог
`src/main`). Совокупный объём с модельными задачами, демонстрациями и бенчмарком —
около 383 КБ (6445 строк в 20 файлах, каталоги `src/main`, `src/problems`, `src/demo`,
`src/benchmark`); с тестами и средствами верификации — 17 485 строк в 62 файлах.

## Год создания

2026.

## Зависимости

- виртуальная машина Java версии 21 или новее;
- numerical-core 1.1.0 (`io.github.egorkakulikov:numerical-core`, лицензия Apache License 2.0) —
  квадратура Гаусса–Лежандра, плотная линейная алгебра, оценка обусловленности, контекст
  вычислений, параллельная сборка матриц;
- minimal-splines 1.1.0 (`io.github.egorkakulikov:minimal-splines`, лицензия Apache License 2.0) —
  сетки с кратными узлами, порождающие системы, базис минимальных сплайнов, семейства
  аппроксимационных функционалов, метрики погрешности;
- через numerical-core — netlib 3.2.0 (`dev.ludovic.netlib`, лицензия MIT), слой доступа
  к BLAS/LAPACK с переносимой реализацией на Java.

Сборка выполняется средствами Gradle 8.9 и Kotlin 2.0.0. Проверка сверки со SciPy требует
дополнительно интерпретатора Python с библиотеками SciPy и NumPy.
